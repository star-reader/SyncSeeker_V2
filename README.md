# SyncSeeker_V2

SKYline SyncSeeker V2, by React + Tauri + Mapbox

SKYline SyncSeeker V2是SyncSeeker的完全重构版，是SKYline查看连飞地图数据的夏天。
V2版本在Mapbox 3D基础上全面重构，正式发布后将会是SKYline Flyleague的下一代模拟飞行连飞服务器航班实时预览与与地图可视化平台

开发与测试环境用的是SKYline Dynamic Server (golang edition, latest)，理论上支持目前市面上全部同输出格式的FSD(session与FlightObject格式)
